GroowAI Backups

GroowAI Backups is an internal operational tool used to store encrypted database backups in Google Drive.

The application uses Google OAuth with the drive.file permission. This permission allows the application to create and manage files created or explicitly opened by the application. It does not provide general access to all files in the user's Google Drive.

Database backups are encrypted before being uploaded to Google Drive.
